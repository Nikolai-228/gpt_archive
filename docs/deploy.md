# Развёртывание системы

Архитектурно система включает веб-сервер, представляющий для пользователей
гипертекстовый интерфейс (работает в среде Node.js), RDF-хранилище данных c
информацией о сущностях (фотографии, люди, события и пр., Apache
Jena Fuseki), а также реляционную базу данных с информацией о пользователях и
их правах (PostgreSQL).

Все компоненты развёрнуты на одной виртуальной машине в ИжГТУ под управлением
операционной системы Ubuntu 24.04.

- [Веб-сервис](./web.md)
- [Fuseki](./fuseki.md)
