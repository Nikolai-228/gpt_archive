# Веб-сервис

Веб-сервис предоставляет пользовательский гипертекстовый интерфейс
к системе и коммуницирует с хранилищем данных [Fuseki](./fuseki.md).
Он работает в среде Node.js. Для сборки используется пакетный менеджер
Yarn.

## Переменные окружения

При запуске могут быть указаны переменные окружения, представленные в таблице.
Они могут быть указаны в файле [config.edn](../web/config.edn). Этот файл уже
включает обязательные переменные со значениями, которые подходят при запуске
Fuseki с [примерной конфигурацией](./fuseki.md).

В случае, если требуется функционал авторизации, также необходимо
указать переменные окружения, требуемые библиотекой [`pg` для
PostgreSQL](https://node-postgres.com/features/connecting).

## Развёртывание

Для развёртывания подготовлен bash-скрипт [deploy.sh](web/deploy.sh),
выполняющий всю работу по обновлению кода. Затем необходимо перезапустить
соответствующий сервис systemd.

## Регистрация пользователей

Для регистрации новых пользователей в системе необходимо подготовить файл в
формате EDN (запись структур данных в синтаксисе Clojure), содержащий
вектор таблиц с данными о пользователях, например:

```clojure
[{:username "ivanov.i"
  :password "as71wxsckqw4793ejx" ; пароль, по которому пользователь будет заходить в систему
  :family-name "Иванов"
  :given-name "Иван"}
 {:username "sidorova.p"
  :password "3820djkxcjkquwo"
  :family-name "Сидорова"
  :given-name "Паулина"}
 ;; и т.д.
]
```

`:username` пользователей должны быть уникальными и не совпадать с уже
существующими пользователями. (СУБД проверяет уникальность и выдаст ошибку.)

Затем необходимо выполнить следующую команду, передав ей в качестве стандартного
ввода (stdin) содержимое ранее подготовленно файла. Перед командой должны быть
указаны переменные окружения для подключения к базе данных.

```bash
node istu-photo-archive/web/build/tools.js
```

Если необходимо зарегистрировать пользователей на удалённом сервере, то данные
можно передать с помощью конвейера в ssh:

```bash
cat users.edn | ssh archive@archive.istu.ru 'PGHOST=localhost...'
```
